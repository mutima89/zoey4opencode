A friendly guide for everyone — no coding experience needed

What is Zoey4OpenCode?

Zoey4OpenCode gives you a team of AI helpers (we call them "companions") that live inside OpenCode, a code-editing tool. Each companion has a different specialty, like researching topics, designing plans, managing servers, or reviewing work.

Think of them like a team of experts you can call on whenever you need help. They also remember things — so if you tell one companion something important, the others will know about it too, even days later.

No technical knowledge needed. If you can type a question, you can use Zoey4OpenCode. Just mention a companion's name (like @Atlas) and ask for help.

How to Talk to Your Companions

It's as simple as typing their name with an @ symbol in front, followed by your question or request.

1
Type @ and the companion's name

For example: @Atlas or @Mentor

2
Tell them what you need

Just ask naturally, like you would a colleague: @Atlas What is the latest version of React?

3
Get your answer

The companion will respond with helpful information, suggestions, or ask clarifying questions.

Example Conversations

  • @Atlas Research the best database for a small business website
  • @Architect How should I organize this project?
  • @Operator Deploy this application step by step
  • @Mentor Can you review this code and suggest improvements?
Tip: You don't need to remember which companion to use. Just describe what you need and the system will help. If you're not sure, start with @Atlas — they're great at figuring out what you need and who can help.

🧠 How Memory Works

Normally, AI assistants forget everything once you close a conversation. Zoey4OpenCode is different. It has a memory — like a notebook that all companions can read and write to.

This means:

  • Tell once, remembered forever — "We decided to use SQLite" gets saved and everyone knows
  • Cross-session memory — What you talked about yesterday is still there today
  • Tag your memories — Add labels like "decision" or "config" to organize things

Simple Memory Commands

  • /memory save "We chose blue for the logo" tags=design,decision — Save something important
  • /memory recall "logo color" — Find what was saved about a topic
  • /memory list — See your recent saved notes
  • /memory stats — See how many memories you have
Pro tip: Get in the habit of saving decisions right after making them. Future you will thank past you when you can instantly recall why something was done a certain way!

❓ Common Questions

I typed @Atlas but nothing happened?

Make sure OpenCode is running and the Zoey plugin is loaded. Try typing /companion list to check if everything is working.

Can I talk to multiple companions at once?

Yes! Each companion works independently. You can ask @Atlas a research question, then immediately ask @Mentor to review something else.

Is my data private?

Absolutely. Everything stays on your computer. The memory database is stored locally in a folder on your machine. Nothing is sent to any cloud service.

What if I want to clear the memory?

You can delete individual memories with /memory forget [id], or remove the entire memory database from the store folder.

Can I customize how a companion behaves?

Yes! Use /companion configure Mentor "instructions" to add custom instructions. For example: "Focus on security when reviewing code."
